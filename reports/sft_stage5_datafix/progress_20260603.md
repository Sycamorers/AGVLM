# Stage5 Data-Fix Progress

Date: 2026-06-03

## Motivation

Stage4 trained cleanly and reduced eval loss, but benchmark classification still collapsed to one dominant label per source. The loss staying near `3` is not by itself proof that the model cannot improve: the SFT loss is token-level cross-entropy over mixed tasks and long labels/format strings. The benchmark is the deciding signal, and Stage4 classification accuracy was only `0.0162`.

Decision for Stage5: treat this as a data/label-space issue, add more scoped agricultural classification data, keep closed-label prompting, and start from the Stage2 adapter instead of the collapsed Stage4 adapter.

| Broad species-ID datasets such as iNatAg | Too generic for V1 default behavior; they risk shifting the model toward species identification rather than crop issue, pest, disease, and consultation tasks. |

## Implemented

- Added registry entries for the four Stage5 classification sources.
- Added downloader materializers for generic HF image classification and Digital Green URL-backed records.
- Made URL-backed downloads resumable and atomic:
  - writes `records.jsonl.tmp` and replaces `records.jsonl` only on completion
  - repairs corrupted temp JSONL tails after interrupted runs
  - verifies contiguous record IDs for completed URL-backed records
  - reuses existing image files during rebuilds
- Added progress logging for long manifest builds behind `AGRI_VLM_MANIFEST_PROGRESS=1`.
- Fixed rice nutrient labels: source labels `N`, `P`, and `K` now normalize to `nitrogen deficiency`, `phosphorus deficiency`, and `potassium deficiency`.
- Added tests for rice English parenthetical labels and nutrient alias expansion.
